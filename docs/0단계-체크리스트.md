# 0단계 사전 검증 — 결과

계획의 전제를 실물로 확인하는 단계였습니다. **끝났습니다.** 이 문서는 이제 할 일 목록이
아니라 **무엇이 확인되었고 무엇이 아직 아닌지의 기록**입니다.

> **이 문서의 값은 0단계 시점의 것입니다. 지금 사실이 아닌 것이 둘 있습니다.**
> 도서관 수는 여기서 1,602곳으로 셌지만 지금은 **1,619곳**이고, 작은도서관이 「없다」고
> 적었지만 실제로는 **1,619곳 가운데 385곳**이 이름에 「작은도서관」을 달고 있습니다.
> **일부러 고치지 않고 둡니다.** 그때 무엇을 알고 있었고 나중에 무엇이 달라졌는지가
> 사라지기 때문입니다. 지금 값은 [`가정과-검증상태.md`](가정과-검증상태.md) 를 보세요.

가장 크게 달라진 것은 이것입니다. **신청할 곳이 세 곳이 아니라 한 곳이었습니다.**
매뉴얼을 열어 보니 정보나루 하나가 도서관 마스터·서지·소장을 모두 주었고, 계획이 필요하다고
보았던 나머지 둘은 1차 범위에서 쓸 일이 없었습니다.

## A. 사람이 해야 했던 일

### A-1. 정보나루 인증키 — 완료

- [x] 회원가입과 **데이터 활용 > 인증키 이용신청**
- [x] 승인
- [x] **마이페이지 > 인증키 관리**에 서버 IP 등록
- [x] 1일 한도 30,000건 적용 확인 (`/api/status` 의 `callsRemaining`)

**인증키를 받는 것과 IP 를 등록하는 것은 한 묶음입니다.** 등록하지 않으면 오류 하나 없이
500건 한도가 적용되고, 평소에는 멀쩡하다가 여러 권 확인 두어 번에 소진되어 「확인 불가」가
쏟아지는 형태로만 드러납니다.

### A-2. 고정 IP — 완료 (Fly.io 아님)

계획은 Fly.io 전용 IPv4(월 약 2달러)를 잡았지만, **Google Compute Engine 무료 등급 VM** 으로
갔습니다. 인스턴스에 붙어 있는 동안 공인 IP 가 무료라 비용이 0원이고, VM 이라 나가는 주소가
하나뿐이라 모호함이 없습니다. 절차는 [`구글-서버-만들기.md`](구글-서버-만들기.md) 에 있습니다.

- [x] VM 생성과 고정 IP 예약
- [x] `curl -s https://api.ipify.org` 로 **실제 나가는 주소를 눈으로 확인**한 뒤 등록

**등록할 것은 나가는(egress) 주소입니다.** 들어오는 주소와 혼동하면 등록이 먹지 않습니다.

### A-3. 국립중앙도서관 서지정보 인증키 — 1차 범위에 필요 없음

계획은 「이것이 없으면 1단계의 검색 대상 자체를 만들 수 없다」고 적었는데 **틀렸습니다.**
매뉴얼을 확인한 결과 서지는 정보나루의 `srchBooks` 로 받습니다. 이 API 는 서지 품질을
보강할 때 붙이면 되고, 그때 화면의 출처 표기도 한 줄 늘어납니다.

### A-4. 공공데이터포털 서비스키 — 필요 없음

계획은 「**도서관부호는 여기서만 나온다**」고 적었는데 **틀렸습니다.** `libSrch` 가 도서관부호와
**위경도까지** 함께 줍니다. 그래서 전국도서관표준데이터를 이름과 주소로 대조하는 단계가
통째로 사라졌습니다. **계획이 가장 큰 위험으로 꼽았던 바로 그 단계입니다.**

## B. 확인된 것

| 질문 | 답 | 근거 |
|---|---|---|
| `libSrchByBook` 의 `region` 이 필수인가 | **필수** | 매뉴얼 13절 |
| `libSrch` 의 `region` 은 | **선택.** 없으면 전국 | 매뉴얼 1절 |
| `libSrch` 가 위경도를 주는가 | **준다** | 매뉴얼 1절, 실제 응답 |
| 관종(도서관유형)을 주는가 | **주지 않는다** | 매뉴얼 1절 응답 명세 |
| 도서관이 몇 곳인가 | **1,602곳** | 실제로 받아 셈 |
| 작은도서관이 들어 있는가 | **없다** | 실제 목록 확인 |
| 오류를 어떻게 돌려주는가 | **HTTP 200 에 본문으로.** 형식이 엔드포인트마다 다름 | 실제로 받은 본문 |
| 도서관의 그 책 페이지 주소를 주는가 | **주지 않는다** | 매뉴얼 1·13절 |

마지막 줄 때문에 도서관별 OPAC 주소 규칙을 우리가 들고 있어야 합니다
(`backend/src/main/resources/opac/templates.csv`).
